# Independent private skill form consumer

Node >=22.12 and exact React/ReactDOM19.3, Zod4.6.5, bs586, tsx4.23.15, TypeScript5.9.3 and matching types are declared by package/lock/config. Canonical source links prevent divergent module copies; the independent consuming check copies their actual targets to a clean temporary host and installs its own node_modules.

From this directory:

```sh
npm ci
npm run typecheck
npm start
```

This synthetic SSR consumer supplies parsed catalog, own claim state, canonical participant ID and explicit transport callbacks. It verifies configured availability, safely disabled controls before hydration, clear unverified labels, denied invalid host data and zero hidden network/app access. Client readiness and interactive controls, browser interaction and actual Root authorization are tested separately against the task-owned real PG/Next preview. SSR supplies no assessment, permission, UAT or release proof.

A consuming application authorizes reads before serializing private claim/catalog/participant props, implements protected save/read/readCatalog, authenticates the current owner at each command, validates original-result receipts, owns no-store/private transport and renders these private routes inside its own layout/styles. Canonical identity is a data binding, never an authorization token; session/actor credentials are not client props. No environment variable, DB or provider credential is required by this console consumer. See the [module and recovery contract](../../docs/raid-skill-claim-form.md).
