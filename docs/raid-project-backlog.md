Open the issue and read outcome, parent epic, repository mapping, required blueprint sections, work checklist, acceptance scenarios and predecessors. Agree a named owner and bounded weekly commitment before starting. Attach actual PR/SHA/environment/results and next-agent handoff before Done. Treat QA, representative UAT and production enablement as separate decisions.
