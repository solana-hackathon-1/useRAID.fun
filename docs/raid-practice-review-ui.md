# Evaluator case evidence screen

The bounded T013 screen shows an explicitly assigned evaluator the original private practice submission, rubric and declared tools/AI assistance. It is an evidence-reading prerequisite for later review decisions. [Protected API](raid-practice-review-http.md) and [current assignment/storage authority](raid-practice-review-reads.md) remain authoritative. R06/R11/R12/R15/R16, I05/I06/I10/I11/I13 and blueprint 07/08/13/23/24/26/28 apply; [task/evidence](tasks/2026-10-21-T013-review-ui.md) records scope and actual verification. Formal independent criterion review, UAT and release approval remain NOT VERIFIED.

## Root route and current access

`/evaluator/practice/{assignmentId}/submissions/{submissionId}?purpose=OWNERSHIP_REVIEW|ASSESSMENT_REVIEW`

This is an exact-case route, not a reviewer directory or assignment-discovery queue. It requires both UUIDs and exactly one supported purpose; unknown/duplicate query fields fail closed. The server loader composes the existing protected GET directly, without a self-HTTP network request, caching layer, new role inference or client authority. The GET resolves the current server session, account rate limit and committed exact-scope audited read. Every opening or native **Recheck access** form submission repeats current assignment/session/purpose/policy/expiry/revocation checks. Each authorized attempt creates the existing private identifier-only audit; it does not record a review finding. GET can create audit noise, including cross-site attempts; it cannot disclose a body without the existing current authority.

Only an authorized successful read renders private HTML/RSC. Generic metadata contains no case title, body, declarations or reviewer information; robots disable indexing. A malformed or missing/denied case uses a generic local not-found screen. Signed-out, denied, rate-limited and unavailable states render safe messages with no stale evidence. These are page states; API401/403/404/429/503 remain distinct from HTML status. Next may stream not-found UI with HTTP200 under an enclosing loading boundary. Production HTML must have private/no-store cache control; the installed Next development server forces `no-cache, must-revalidate` for HTML, so development fixtures are synthetic only. The protected API retains private/no-store and Vary Cookie in both modes.

The page renders the exact original answer and explanation as escaped, wrapping text, never executable HTML, a link preview, uploaded public asset, sandbox runner or fetched URL. CRLF in source remains exact; HTML parsing normalizes line endings visually. Required/optional original criteria and version IDs, task/variant/materials, tool policy, AI disclosure, pass conditions, expected time (not a deadline), attempt/cooldown and accommodation policy are available. Submitted tool/AI declarations do not establish compliance or originality. Original ownership remains UNCONFIRMED; this original record does not include later ownership findings or current assessment state. Practice target rank describes the original exercise, not an earned rank.

Assignment expiry is displayed with an explicit UTC timezone. A read is a point-in-time observation, not a permission lease. Rechecking can remove access; a server cannot recall a body already disclosed, a saved copy or browser history. There is no client case store, service worker, polling, automatic prefetch of this case, or duplicate hydration request. Later current-state decisions must use their own actual policy/context/CAS/idempotent command, not this view as authority.

## Reusable contracts and dependencies

- `createPracticeReviewPageLoader(get)` in `src/skills/practice-review-page.ts` takes an injected native protected GET dispatcher and returns canonical v1 scope plus `READY`, `SIGN_IN`, `DENIED`, `NOT_FOUND`, `RATE_LIMITED` or `UNAVAILABLE`. It uses the existing exported `PracticeReviewHttpResultSchema` and storage input/record schemas, not a parallel browser schema. It is server-only because the canonical dependency tree includes Node crypto. The dispatcher owns actual current authorization, commit-before-delivery, safe diagnostics and private caching. A redirect or malformed/mismatched success cannot become evidence.
- `PracticeReviewCase({review})` in `src/components/practice-review-case.tsx` is a stateless portable React view. Its host must supply the canonically validated, authorized DTO; the renderer itself confers no authority. Its storage DTO import is type-only and has no runtime Node/Next/Prisma dependency. Text is escaped by React; no dispatch or mutation occurs during rendering. Native details/summary sections and semantic headings support keyboard reading and wrapping on mobile. This is not a complete WCAG conformance claim.
- Root `src/lib/practice-review-page.ts` injects the real protected GET. The dynamic page supplies generic metadata, loading/not-found/failure states and a native same-case GET recheck form. No case-specific data is passed to a client component. Server feature `PRACTICE_REVIEW_READS_ENABLED` retains exact-true/default-off behavior. There is no new flag or production configuration change.

The [separately installable PostgreSQL/HTTP/React host](../examples/practice-review-reads/README.md) declares React/ReactDOM/type dependencies and canonical component/source links. It renders an actual committed, authorized HTTP record after strict parsing, verifies original evidence/no mutation and retains actual foreign-purpose/admin/revocation tests. It supplies its own account/session/SQL/current policy/driver lifetime. The Root desktop/mobile browser fixtures use a separate disposable database; they never truncate an existing preview. The browser suite is registered for development and production in the CI workflow; hosted execution remains separate evidence.

No migration or business state transition is introduced. Rollback disables review reads and retains immutable submissions/assignments/revocations/audits and separate owner access. The evaluator command UI, current findings, notice/appeal/operating model, calibration, retention and independent/UAT/release acceptance remain subsequent obligations.
