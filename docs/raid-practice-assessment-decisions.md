# Reasoned practice assessment decisions — v1

The PostgreSQL module appends an actual private manually attributed case and a new committed assessment version. `recordPracticeAssessmentDecision(tx, command, options)` accepts an actual evaluator/own-session actor, normalized versioned input, idempotency key and request ID. It returns EXECUTED/REPLAYED and a private decision view after the consuming host commits. `readPracticeTrialAssessmentState(tx, actor, input, canRead)` and `readPracticeAssessmentDecision(...)` return current or explicitly requested historical same-case snapshots under current actual ASSESSMENT_REVIEW assignment authority; unavailable resources return null. Never treat a snapshot or context as a grant, delivery receipt or current eligibility token.

Input binds exact expected participant-skill assessment, current original-case review, current ownership finding and current approved assessment-policy references. Discover them using the audited assigned-case context observer and actual approved-policy observer; do not guess a revision or trust caller-provided approval/evidence labels. Only the case that produced the current assessment can affect it. An old-case appointment cannot revoke a newer unrelated-case verification. The module reads/audits the original saved private answer/definition, current review, current ownership, actual policy and exact prior assessment under held transaction locks. A human decision is attributable under that actual policy; storage cannot prove that a person performed an interview or independently validate their findings.

REQUIRE_REASSESSMENT with CAPABILITY_RECHECK requires a future millisecond UTC dueAt and at least one specific CAPABILITY_EVIDENCE finding. It transitions VERIFIED→REASSESSMENT_REQUIRED. REVOKE with FRAUDULENT_ASSESSMENT_EVIDENCE requires null dueAt and specific ASSESSMENT_EVIDENCE or OWNERSHIP_EVIDENCE findings; it transitions VERIFIED or REASSESSMENT_REQUIRED→REVOKED. Normalized reason and finding detail are each bounded to2000UTF16 units, well-formed and nonempty;1–20 findings. Unsupported categories, arbitrary rank/sample/approval/evidence additions and repeated/revival actions fail closed. A new actual review/verification is required to restore verification. No default fraud threshold, automated verdict, reliability/account restriction, financial recovery, provider call or appeal-finality policy is introduced. Similarity, AI/network/reputation signals alone are never automatic conviction. Public operation/notice/appeal/staffing/retention and independent acceptance remain NOT VERIFIED and gate their dependent enablement.

Migration35 adds immutable PracticeAssessmentDecision and nullable SkillAssessmentVersion decision provenance. Original verified versions and original review-issued references stay unchanged. Their policy/evaluator/issue time reflect the new attributable decision; the view separately includes the prior snapshot and case findings. Original verification remains historical and `isCurrent:false`. The current pointer advances by contiguous CAS exactly once. The original-review partial uniqueness applies only to issuance rows; decision versions deliberately retain that original lineage.
