## Privacy, authority and money (I06, I10, 16.13)

- Errors carry the code only (verified by S5 and the real-Prisma test); the module has no logging; conflict responses are one shape for primary, active-link and revoked-link owners (unit test); probing ownership requires a valid signature for the probed address, so there is no enumeration of foreign wallets.
- `publicWalletLink` omits account, participant and link ids; `listWalletLinks` returns link ids and is documented as internal-only.
- The command never reads or writes `WalletIdentity` for payout, `BalanceEntry`, transfers, allocations or enrollments; snapshots of all six money/payout tables are unchanged in the D1 test (16.13). Rotation still works with links present and refuses an own-link target at the trigger.
- Actor authority is host-supplied; the module checks equality only and the docs say so. Nothing in `src/app` or `src/lib` calls the module.
