# Own current skill assessment — v1

`readOwnSkillAssessment(tx, actor, {version:'v1', taxonomyId, skillId}, canRead)` returns a private current summary and a separate trusted-host observation. Actual own unrestricted User/Session and canonical HUMAN Participant, actual published taxonomy/skill/domain and the canonical participant-skill current pointer are required. Caller participant IDs, old version selectors, claim levels and approval labels are rejected. A real claim without an actual assessment returns NO_ASSESSMENT. Roles do not grant another participant's summary or private case notes.

The bounded `view` includes skill name/identity/domain/current taxonomy reference, current assessment reference, recorded state, effective status, assessed rank, recorded/reassessment dates, decision reason category and actual database observedAt. It never includes an answer, explanation, evaluator case reason/findings/confidence or internal evidence. Stored VERIFIED with a due reassessment date has effective REASSESSMENT_REQUIRED without rewriting history. Current REASSESSMENT_REQUIRED/REVOKED never appear verified. Policy withdrawal or an expired external credential does not silently revoke documented capability; actual current case decisions own those state changes.

The separate backend observation includes the actual canonical participant, taxonomy and current ASSESSMENT evidence fact, plus observedAt/accessId. It contains source references/policy/evaluator identity for a trusted authorized consuming host and is not an HTTP/client payload. Root strips it before delivery. Nothing returned is a permission, acceptance or future-validity token; reads create no assessment, work reservation, grant, account restriction, financial obligation or provider operation.
